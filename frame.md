# Frame direction

The deck uses ADC Neutral Light for explanation and ADC Primary navy for
thresholds, technical core ideas, and the demo bridge. The change is narrative,
never decorative.

The four-region map is the persistent spatial anchor. Regions keep their position
across the deck; the active region turns ADC Accent amber while the rest recede.

Color has semantics: ADC Primary is evidence/context, ADC Accent is action or
attention, Success is verified success, and Error is failure or blocked action.
Do not use these colors as interchangeable decoration. Primary Tint is decorative
only and is never used for body text.

Every slide has one sentence-claim headline and one dominant visual. Cards are used
only when the content is actually a set of bounded objects. Avoid gradients, glass,
neon, ornamental code, and logo walls.

Turkish copy uses sentence case. Every sentence begins with a capital letter. Do
not use em dash or en dash characters; use punctuation or a short hyphen where the
announced event title requires it.
